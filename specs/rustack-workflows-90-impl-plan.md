Available: existing gateway/YAML/snapshot infrastructure and independent Native/Squib backends; Lambda control plane, immutable revision/artifact capture and supervised admission/cancellation; shared RuntimeSession/HTTP/relay/client, bounded DockerWire, platform-aware image resolution/leases and provider asynchronous deployment/status/CAS. Missing: production runtime startup construction; historical-effect reconciliation, allowed pulls, endpoint reachability and final startup/configuration/capabilities; Step Functions HTTP/core, ASL engine, integrations, workflow snapshots and complete acceptance fixtures. The execution ledger distinguishes implemented foundations from full phase exits.

Existing [Cargo Lambda evidence](../docs/research/spike-cargo-lambda-runtime-execution.md) establishes the bootstrap protocol but cannot close Docker/platform risks. P0 must precede production implementation. ## 2. Effort model

Execution priority update (2026-10-26, explicit user direction): defer further Docker-image work and advance the Step Functions API/compiler/engine and subsequent workflow features first. P2 protocol, registry and pure semantics do not require Docker readiness. Qualify LambdaTaskPort against existing real execution backends while preserving the final real-image acceptance requirements. Do not mark M0/M1–M4 complete until their original image/platform gates are backfilled. The in-progress image-pin journal worktree is retained as a deferred checkpoint; no new Docker experimentation is required before proceeding with Step Functions.

## 9. Why this order is necessary

Cancellation/revision contracts precede both the Docker executor and workflow bridge; otherwise stopping a Task leaks resources or reuses mutable code. Compiler and history semantics precede Parallel/Map so branch machinery has one data/error contract. Child subscription/admission rules precede `.sync` so fast completion cannot be missed and parents cannot block child capacity. Snapshot integration follows fully settled lifecycle semantics, avoiding archives that appear resumable while silently replaying side effects.

Implement phases with the repository's impl workflow and its independent review requirement. Specification publication and P0 feasibility evidence alone do not establish production runtime acceptance.
